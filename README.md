# sec3-graphql-alias

攻击者在一个请求里用几百个别名重复同一个查询，限流只按请求数算，等于一次拿到几百次调用：别名数量必须计入成本；同一字段的多次别名调用必须合并计费；成本必须按字段权重求和；成本超限必须拒绝；内省与普通查询分别计费；批量校验各查询独立。不变量：任何查询的成本都不超过策略上限；同一查询两次计价结果相同。
